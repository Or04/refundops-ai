# Demo recording included

The submission includes [`RefundOps_White_Studio_Demo.mp4`](RefundOps_White_Studio_Demo.mp4), a **4m17s silent screen recording with on-screen captions**. It walks through the actual local FastAPI-connected UI, reviewer escalation, investigation trace, policy draft, historical replay, activation and audit ledger.

The browser runner bridged API requests to the live local Python server because sandbox browser policy blocks direct localhost navigation. This does not simulate decisions: the Python backend actually processed the requests. No real payments are executed.
